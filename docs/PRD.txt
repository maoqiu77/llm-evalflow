产品方案：大模型问答评测与 Badcase 归因分析平台
===============================================

一、背景
AI 产品经理在模型效果验收、竞品分析和需求迭代中，需要反复构建评测集、收集模型回答、评分、分析 Badcase，并沉淀优化建议。手工使用 Excel 效率低，结果难复盘。

二、目标用户
1. AI 产品经理
2. 大模型问答策略产品
3. Agent 产品经理
4. 数据标注和评测运营人员

三、产品目标
建立一个轻量 Web 平台，完成“评测集管理 - 多模型回答对比 - 自动评分 - Badcase 归因 - 优化建议输出”的闭环。

四、核心功能
1. 评测集管理
支持新增、CSV 导入、场景和难度标注。

2. 多模型对比
支持对同一问题选择不同模型生成回答，并展示横向差异。

3. 六维评分
评分维度包括准确性、完整性、指令遵循、可执行性、格式稳定性、用户体验。

4. Badcase 归因
将低分样本归因为事实错误、答非所问、信息遗漏、指令不遵循、格式不稳定、场景理解错误、安全边界过度、安全边界不足。

5. Prompt 迭代记录
记录 Prompt 版本、修改原因、关联 Badcase、修改前后效果和结论。

6. 报告输出
自动生成 Markdown 报告，包含评测概览、模型表现、场景表现、Badcase 类型和产品建议。

五、核心指标
1. 平均得分
2. Badcase 数量和占比
3. 各模型平均分
4. 各场景平均分
5. 各 Badcase 类型分布
6. Prompt 版本前后得分变化

六、MVP 范围
本版本实现 FastAPI + React + SQLite Demo，不做用户系统、权限管理和复杂异步任务队列。

七、后续迭代
1. 支持批量模型调用
2. 支持 Excel 导入导出
3. 支持评分人一致性分析
4. 支持 Prompt A/B Test
5. 支持回归测试集管理
6. 支持 PostgreSQL 和多人协作
