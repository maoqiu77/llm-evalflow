功能更新说明
============

本轮新增/优化内容：

1. 常驻展示
新增 GitHub 静态快照导出。评测结果可固化为 demo-data.json，在 GitHub Pages 中展示。

2. 动态调整问题
评测集页面支持：
- 手动新增问题
- 选择场景方向
- 填写期望行为（作为评分参考口径）
- 编辑已有 Case
- 删除 Case，并自动清理关联回答、评分和 Badcase
- 搜索问题或期望行为
- 按场景筛选
- 查看每条 Case 的回答覆盖和评分进度

3. 更方便的批量流程
模型对比页面支持：
- 一键生成全部模型回答
- 一键自动评分
- 单条回答补评分

4. 图表优化
Dashboard 中模型横坐标使用短名称，例如 gpt、claude、gemini、qwen。
鼠标悬停柱体时显示完整模型名称和分数。
不同模型柱体使用不同颜色，提升可读性。

5. 评测逻辑与公平性说明增强
项目说明中进一步明确：
- expected_answer 更准确地说是“期望行为 / 评分参考口径”，不是唯一标准答案
- 评分采用“硬规则 + 独立评审模型”两层机制
- 当被评模型与评审模型相同时，会自动切换备用评审模型，降低自评偏差
- 当前版本的局限包括人工口径主观性、单评审模型偏差、尚未加入人工复核与多评审投票
- 后续可继续引入结构化评分点、人工复核、场景权重、多评审模型交叉评分等机制

6. 启动说明已更新
README 和 PowerShell 启动脚本已从旧电脑绝对路径改为项目相对路径：
- 后端：cd backend / python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
- 前端：cd frontend / npm install / npm run dev
这样项目迁移到新电脑或提交到 GitHub 后仍可直接使用。
