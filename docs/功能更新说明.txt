功能更新说明
============

本轮新增功能：

1. 常驻展示
新增 GitHub 静态快照导出。评测结果可固化为 demo-data.json，在 GitHub Pages 中展示。

2. 动态调整问题
评测集页面支持：
- 手动新增问题
- 选择场景方向
- 填写标准答案或期望行为
- 编辑已有 Case
- 删除 Case，并自动清理关联回答、评分和 Badcase
- 搜索问题或标准答案
- 按场景筛选
- 查看每条 Case 的回答覆盖和评分进度

3. 更方便的批量流程
模型对比页面支持：
- 一键生成全部模型回答
- 一键自动评分
- 单条回答补评分

4. 图表优化
Dashboard 中模型横坐标使用短名称，例如 gpt、claude、gemini、qwen。
鼠标悬停柱体时显示完整模型名称和分数。
不同模型柱体使用不同颜色，提升可读性。
